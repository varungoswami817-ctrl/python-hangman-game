# Python Hangman Game 🎮

A simple text-based Hangman game developed using Python as part of my Python learning journey and a task assigned by CodeAlpha.

## Features

* 5 predefined words
* One-letter guessing
* Maximum 6 wrong guesses
* Basic input validation
* Console-based gameplay

## Python Concepts Used

* Variables
* Lists
* If-else conditions
* For and while loops
* User input
* String methods
* Random module

## How to Run

1. Download or clone this repository.
2. Make sure Python is installed.
3. Open the project folder in VS Code or terminal.
4. Run:

```bash
python hangman.py
```

## Project

This project helped me practice Python fundamentals and understand how different programming concepts can be combined to create a simple working application.
